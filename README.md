# 🚀 Fullstack-Lab : Angular 20 & Spring Boot 3 (Docker Ready)

Ce projet est un environnement complet démontrant l'intégration d'une architecture **Contract-First** avec génération de code API.

## 🛠️ Architecture
- **Frontend** : Angular 20 (Signals, Standalone)
- **Backend** : Spring Boot 3 (Java 17, JPA, PostgreSQL)
- **Infrastructure** : Orchestration Docker Compose

## 🐳 Lancement Rapide (Docker)

Assurez-vous d'avoir Docker Desktop lancé, puis exécutez :

```bash
docker-compose up --build
```
- **Frontend :**  http://localhost:4242
- **Backend Swagger :** http://localhost:8081/swagger-ui/index.html
